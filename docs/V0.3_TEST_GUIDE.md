# JujutsuCraft NPC Compatibility — experimental v0.3

Forge 1.20.1, JujutsuCraft v51, Easy NPC 7.15.0, CustomNPCs GBPort.

**This is a test build. Forge compilation does not prove that upstream
JujutsuCraft procedure calls actually cast a technique on an NPC.**

## Test sequence
1. Test in a BACKUP world/profile. Remove the previous addon JAR; do not run two versions together.
2. `/give @s jujutsunpccompat:editor_tool`, right-click a humanoid Easy NPC or CustomNPCs entity in Creative/OP mode.
3. Choose one technique, enable one move as Both, and save.
4. Configure original NPC targeting through the NPC's own editor.
5. Test `/jjknpc inspect <npc_selector>` to see health, invulnerability, targeting,
   and for CustomNPCs the player's friendship with its native faction.
6. Test `/jjknpc animate <npc_selector> red` to test original animation playback independently
   of JJK procedure execution. Other original names include `clap`, `punch_right`,
   `domain_expansion1`.
7. Test manual cast:
   `/jjknpc cast <npc_selector> red entity <target_selector>`
   (set move to Triggered or Both first).
8. In the editor's Combat & Movement tab, set Hold position after fighting = true
   to stop active navigation when the NPC loses its enemy after entering combat.

## Damage limitation discovered from upstream bytecode
CustomNPCs GBPort `EntityNPCInterface.hurt` rejects attacks from a player
whose faction is friendly to the NPC. This return happens before usual damage
events; our recovery listener cannot fix it. Change faction/player relation
in the CustomNPCs editor if you want a friendly NPC to be attackable.
Other native NPC settings can independently make NPCs invulnerable.
The addon does not override these native damage/faction policies.

## Technique scope
16 selectable entries including none; 15 techniques total, with 30+ procedure
entry points whose classes and execute signatures exist in v51. **Not all casts
are verified or necessarily functional**, as several procedures depend on
JJK player capabilities, scoreboards or entity type. Experimental domain
entries are manually triggerable only; automatic domain creation and clashes
are not implemented. They may be no-ops, and testing them may modify the world.

CustomNPCs ClassicPlayer pose override has an optional animation mixin.
Easy NPC custom skeletons and all non-HumanoidModel renderers still require
separate adapters; original effects, timing and animations are NOT fully tested.

## Logs
If a move prints 'Attempted' but has no visible effect, that message means only
that the Java procedure returned; it does not prove a spell was spawned.
Upload the full `logs/latest.log` and say which NPC type, move and target
you used. Test singleplayer on a separate profile before a large modpack.
