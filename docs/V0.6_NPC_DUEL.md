# NPC-versus-NPC melee fix — v0.6 experimental

This update specifically targets **NPCs failing to damage other NPCs**.
**No healing, regeneration, or RCT code has been changed.**

## What changed
* Native CustomNPCs can animate an attack while its target refuses incoming damage
  because both NPCs have the same faction. The v0.5 opt-in target-side protection
  patch remains in place.
* A server-side NPC melee bridge observes actual Forge `LivingDamageEvent` hits.
  It lets normal NPC attacks run first. When a configured target has taken no
  recent damage from its opponent despite being in melee range, the bridge
  retries native melee once and then falls back to standard Minecraft
  `LivingEntity.hurt` (armor, damage immunity, Forge damage, death still apply).
* Its opt-in victim flag `Allow combat damage` must be ON; other NPCs and
  noncombat entities aren't affected. No global faction or spawn changes.
* An optional `/jjknpc duel` command establishes a mutual target for two
  compatible NPCs even when native faction selectors refuse to engage.

## Test in a BACKUP world
1. Remove v0.5. Install only this v0.6 JAR for the addon.
2. Set each test NPC to a unique name (for example KolbrunA and KolbrunB).
3. As Creative/OP, run:
   `/jjknpc duel @e[name=KolbrunA,limit=1] @e[name=KolbrunB,limit=1]`
   This explicitly switches **Allow combat damage** ON for both NPCs. It
   preserves ALL healing and regeneration settings unchanged.
4. Watch their health and run:
   `/jjknpc inspect @e[name=KolbrunA,limit=1]`
   `/jjknpc inspect @e[name=KolbrunB,limit=1]`
5. Stop the test with:
   `/jjknpc duelstop @e[name=KolbrunA,limit=1]`

## Limitations
* Physical melee is the target of this fix; ownerless or player-only JujutsuCraft
  spell damage and sure-hit domains remain a different integration problem.
* Regular NPC native hostility and targeting still depend on faction/AI configuration.
  Use the explicit duel command to force test targeting, without changing factions.
* The melee fallback applies only when a compatible NPC attacks another compatible
  NPC, victim has opted into damage, both are alive and in line of sight and melee range.
* Native NPC scripts may run on retry, and damage is not guaranteed if a different
  protection mod cancels the Forge event. The build needs **in-game validation**.
