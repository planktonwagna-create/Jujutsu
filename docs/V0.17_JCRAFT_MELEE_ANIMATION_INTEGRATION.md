# v0.17 — JCraft 0.18.2 runtime melee animation integration

## Dependencies

Minecraft Java 1.20.1 / Forge 47.4.26 / JujutsuCraft v51 /
Easy NPC 7.15.0 / CustomNPCs GBPort.

**Optional**: JCraft Forge 0.18.2 as an animation resource provider.
JCraft's own Forge `mods.toml` requires Architectury >=9.2.14,
AzureLib >=1.3.2, PlayerAnimator >=1.0.2-rc1+1.20 (client),
and Cloth Config >=11.1.118. Install those dependencies exactly as
required by your JCraft version.

**No JCraft assets copied** to the compatibility addon. At runtime
the client reads JCraft's own `jcraft:player_animation/...` resources.
Without JCraft installed, the client falls back to the previous native
JujutsuCraft humanoid animation names.

## Mappings

| Action | JCraft animation | Resource |
|---|---|---|
| Basic melee hit | br.gut | spec/brawler.animation.json |
| Knockback strike | br.upct | spec/brawler.animation.json |
| Universal barrage | br.3hit | spec/brawler.animation.json |
| Ordinary successful hits | br.gut / br.upct | spec/brawler.animation.json |
| Kashimo spinning kick | br.kck | spec/brawler.animation.json |
| Kashimo and other kicks | br.lkk / br.low | spec/brawler.animation.json |
| Sukuna / Dabura melee combos | br.3hit / vm.5hit | brawler, vampire files |
| Generic sword melee hits | an.slsh / an.swp / an.2hit | spec/anubis.animation.json |
| Kusakabe Iai Yuduki | an.usa | spec/anubis.animation.json |
| Nanami weapon slash | an.slsh | spec/anubis.animation.json |
| Backdash | bdash | dashes.json |
| Short forward chase during a duel | dash | dashes.json |

The *only* changes to automatic technique animation dispatch target
recognized melee/kick/sword procedures. Pure cursed techniques and
domain poses continue to use JujutsuCraft's native animations.

## Renderer integration

v0.16's animation system expects JJK bone identifiers like
`right_arm` / `left_arm`; JCraft uses `rightArm` / `leftArm`
and a `torso` bone. v0.17 handles both skeleton conventions,
reads rotation AND position keyframes, uses JCraft's original
`animation_length` without stretching the keyframes and respects
keyframe easing including `easeInOutSine`, `easeOutBack`,
`easeInOutBack`, `easeOutBounce`, `easeInSine`,
`easeOutSine`, `easeInOutCirc` and `easeOutCubic`.

Anim keys are sent over the existing server/client animation packet
using safe lowercase IDs like `jc_br_gut`, which the client resolves
against a fixed whitelist of JCraft animation names and resource paths.
The mod never accepts arbitrary client-loaded paths from the server.

## Testing

1. Install JCraft 0.18.2 and its required dependencies on your test
   client. If joining a modded dedicated server that has JCraft,
   install those dependencies on the server too.
2. Use the new **v0.17** Jujutsu NPC Compat JAR *instead* of v0.16.
3. Run `/jjknpc version` to confirm v0.17.
4. Test unarmed NPC duels: ordinary melee should animate using Brawler,
   while a barrage uses the longer three-hit motion.
5. Give an NPC a sword (vanilla SwordItem or a sword/katana/blade
   item); ordinary melee should animate using Anubis attacks.
6. Enable Backdash and test it near an enemy. The NPC should display
   the JCraft backdash pose while its original backdash movement runs.
7. Test Kashimo spinning kick, Kusakabe sword move, and ordinary
   domain or cursed technique casts. The latter should retain original
   JujutsuCraft animations.
8. Remove JCraft temporarily from a separate test profile (and don't
   leave JCraft-specific items/entities in that save) to check
   fallback JJK animation behavior.

## Limitations

JCraft's actual player skeleton is not completely identical to the
six-bone humanoid NPC renderers. This addon adapts rotations,
positions and easing but cannot perfectly reproduce custom extra
bones / root-motion attacks. A successful Forge build validates only
compilation; smoothness and correctness MUST be confirmed in-game.

Server-wide sound toggles, v0.16 traveling Kashimo lightning, melee
damage compatibility, domains, per-move cooldowns and damage,
technique restrictions, RCT, NPC editor, and gray Kashimo hair
are preserved.
