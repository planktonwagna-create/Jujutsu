# v0.16 Kashimo target-locked, travelling blue lightning
Forge 1.20.1 • JujutsuCraft ver51 • Easy NPC and CustomNPCs

## What changed
**Previously v0.15:** Kashimo's NPC-only Lightning Strike damaged its selected
opponent immediately, then spawned a few original `particle_thunder_blue`
particles at the impact. It did NOT produce the visible lightning path.

**Now v0.16:** Kashimo's Lightning Strike first locks its AI target and starts
a short bolt at the caster's eye/hand area. For 5–18 server ticks
(0.25–0.9 seconds depending on distance) it advances in short, slightly
jagged connected segments toward that same target. It draws those segments
using the two *original JujutsuCraft v51 particle types*:
`jujutsucraft:particle_thunder_blue_mini` and
`jujutsucraft:particle_thunder_blue`. This follows the original procedure's
particle family without running its uncontrolled player-oriented AoE attack.

The victim's position is updated **each tick**, so the travelling spark path
continues tracking a moving enemy. On arrival it emits the native blue
thunder impact particles, plays original `electric_shock` (at start) and
`thunder_impact` (at impact), and deals **one targeted hit**. No other
bystanders receive the attack.

This is a NEW npc-side trajectory for original v51 particles, **not a claim
that every single animation frame of the upstream native procedure has been
recreated**. The original LightningStrike/LightningStrike2 procedures use
player-specific counters and directional inputs; re-running them would
bypass the addon target-lock behavior.

## Gameplay guarantees and limits
* Exactly one target is selected when cast begins: current `Mob.getTarget()`;
  manual explicit target only if the NPC does not have a live AI target.
* It tracks that same enemy until impact; it does not retarget bystanders.
* Damage is applied at visible impact, not instantly at cast start.
* Independent Lightning Strike cooldown and custom damage value still apply.
* An ongoing bolt prevents additional NPC casts until it completes.
* Target removal, target death, range >128 blocks or NPC death cancels the
  unfinished bolt without damaging another target.
* Minecraft normal armor, hurt invulnerability and Forge damage hooks
  remain in effect. 'Sure-hit' refers to targeting, not overriding immunity.
* Original JJK blue particles are used instead of vanilla End Rod or Electric Spark.
* Server-side particles replicate to nearby clients, including dedicated servers.

## Installation / tests
1. Back up the world. Replace ONLY previous Jujutsu NPC Compat JAR with v0.16.
2. Run `/jjknpc version` — must say v0.16.
3. Set Kashimo Lightning Strike to Automatic/Both with cooldown and damage.
4. Lock the NPC onto another NPC; observe a blue bolt visibly travelling
   from Kashimo toward its moving opponent. HP changes once on impact.
5. Confirm the same occurs when the target changes its position during the bolt.
6. Compare the native Kashimo NPC's original lightning animation to the
   addon implementation. If the bolt is too slow, sparse, or looks
   different, share a video for tuning.

v0.15 animation fixes, server-wide NPC/player hit-sound toggle, weapon moves,
