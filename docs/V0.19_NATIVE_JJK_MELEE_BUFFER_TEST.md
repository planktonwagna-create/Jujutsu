# v0.19 — Original JujutsuCraft melee animations with v0.18 pacing

## Goal: controlled animation comparison
Restore JujutsuCraft ver51's original humanoid melee and mobility animations,
while retaining the v0.18 **pre-hit animation windup**, **misses animate**,
**shared stagger for two fighting NPCs** and the 1–2 second configurable
ordinary melee interval.

JCraft is NOT required. Its optional dependency entry has been removed
from mods.toml, and the player animation adapter has returned to loading
only `jujutsucraft:player_animation/*.json` directly out of the installed
JujutsuCraft v51 mod.

This deliberately tests the difference between the original JJK clip
content and the JCraft animations; no unrelated combat logic is changed.

## Original JJK v51 animation mappings

* Unarmed hits: `punch_right` → `punch_left` → `punch_both`
* Sword-equipped NPC melee: `sword_to_right` → `sword_to_left` → `sword_rotate`
* Basic universal Attack: `punch_right`
* Knockback Attack: `punch_both`
* Barrage: `combo1`
* Kashimo kicking: `kashimo_kick`
* Generic kicking: `kick_right`
* Regular speed attack: `speed_attack_punch`
* Sukuna & Dabura combos: `combo1`, `combo2`, `combo3`
* Yuduki/Iai quickdraw: `speed_attack_sword`
* Nanami weapon skills: `sword_to_right`
* NPC chase approach: `step_front`
* Automatic backdash: `backstep`
* Cursed techniques and domain animation mappings otherwise unchanged

Unlike `punch_gomu_gatling1`, `speed_attack1`, and some `iai1`
variants, the chosen animation files have actual timestamped rotation
and position tracks in the original JujutsuCraft v51 JAR. Avoid mapping
purely static placeholder clips.

## What is NOT changed from v0.18

* NPC ordinary melee buffer defaults to **30 ticks = 1.5 seconds**.
* Minimum **20 ticks = 1 second**; maximum **40 ticks = 2 seconds**.
* Two compatible NPCs fighting one another share the cooldown to avoid
  initiating simultaneous ordinary melee strikes.
* On a valid attack attempt, play an animation immediately, wait six
  server ticks, then attempt the hit. Even a miss, dodge, shield block or
  no-damage result is animated.
* Native NPC `Mob.doHurtTarget` and existing opt-in fallback damage
  compatibility remain unchanged.
* Kashimo's target-locked zigzag lightning, custom `damage_curse`
  damage type, reduced native particle trail and independent cooldown
  remain unchanged.
* Domain expansion, anti-domain, RCT, sound controls, editor, blacklisted
  natural mob spawning and grey Kashimo hair remain unchanged.

Config: `world/serverconfig/jujutsunpccompat-server.toml`:

```toml
[combat]
    meleeAttackBufferTicks = 30
```

## Test
1. Remove the old v0.18 addon JAR and install v0.19 only; back up save.
2. Run `/jjknpc version` and verify v0.19.
3. Duel two configured NPCs with hit compatibility enabled.
4. Observe pre-hit original JJK right/left/both punches with the
   familiar v0.18 1.5-second stagger. Misses should still animate.
5. Equip sword on one NPC, then try original JJK sword animation.
6. Verify original JJK backdash and check no JCraft dependency is needed.
7. Try Kashimo lightning to ensure v0.18 lightning behavior is retained.

Build success confirms compilation and packaging only, not visual quality
inside Minecraft. Some original JJK animations are designed for a more
complex player skeleton; the six-part NPC renderer still requires
in-game evaluation.
