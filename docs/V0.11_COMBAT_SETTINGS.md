# JujutsuCraft NPC Compatibility v0.11 (experimental)

Targets Forge 1.20.1, JujutsuCraft v51, Easy NPC 7.15.0 and CustomNPCs GBPort.

## New
- **Move damage:** In Timers > Edit Move Damage, toggle Native JJK / Custom. A custom value of 0–10000 health points applies to a configured NPC's native RangeAttack damage payload and to attributable direct damage during an active cast. Native JJK leaves upstream values unchanged. This does not rewrite damage from unrelated projectile owners or every indirectly spawned entity.
- **Domain sure-hit damage:** Domain > Edit Sure-Hit Damage: Native JJK or custom (0–10000). Intercepts v51's *RangeAttackProcedure* when the original `DomainAttack` flag is set, replacing its native `Damage` parameter. This does not manufacture sure hits when the original domain never enters its active stage.
- **Easy NPC animation:** Apply native v51 animation to the Easy NPC model manager AFTER its own final pose setup. Existing HumanoidModel, PlayerModel, and CustomNPCs classic hooks remain installed. Test with the original Easy NPC player-model renderer.
- **Kashimo passive:** With Kashimo technique and Technique Passives enabled, successive valid damaging hits on one specific target accumulate three electric marks, followed by a guaranteed *target-specific* electric hit and particles. The addon uses target-specific Forge damage for this compatibility fallback, not JujutsuCraft's player-only charge system. The original JJK lightning mechanics can differ. All other 47 technique passive implementations are NOT certified in this version.
- **Backdash:** Combat > Passives & Backdash exposes toggle and independent cooldown (0–3600 sec); close-range NPCs receive a velocity impulse away from the current enemy and the original v51 `backstep` animation. This is NOT a teleport and can be blocked by world collision/pathfinding.
- **Time Cell Moon Palace:** Extend its original caster procedure sequence from 95 to 190 ticks. This is a conservative lifecycle attempt to allow the native barrier/effect setup to complete. It does NOT guarantee barrier persistence/sure-hit; an in-game test and logs are required.
- **Old Kashimo hair:** `jujutsunpccompat:kashimo_hair_grey` armor head item (creative/commands), with the original Kashimo hair geometry via client reflection and recolored pixel-preserving textures. If original JJK geometry lookup fails, vanilla helmet geometry is used as a fallback. Custom grey textures are embedded in the downloadable packaged test JAR.
- The NPC-on-NPC melee damage, domain, charge, crouch, RCT, weapon and cool-down behavior from v0.10 are preserved.

## Test checklist
1. BACK UP YOUR WORLD. Remove any older addon JAR and install the v0.11 file.
2. Run `/jjknpc version`. Right-click a supported NPC holding `jujutsunpccompat:editor_tool`.
3. Select a technique move, open **Timers**, choose Edit Move Damage, turn on Custom damage and enter a value. Use two supported NPCs in a fight and compare health changes.
4. Domain page: set Sure-Hit Damage, confirm damage ONLY after the original domain is genuinely active. Test in a backup world.
5. With Easy NPC's *player* renderer and a JJK move selected, verify animations. If they do not show, try `/jjknpc animate @e[name=Example,limit=1] punch_right` and attach `latest.log`.
6. Give `/give @s jujutsunpccompat:kashimo_hair_grey`. Equip and confirm the hair appears grey.
7. Enable Kashimo passives and hit the same enemy repeatedly. Verify the third hit triggers a single-target electric effect.
8. Enable backdash and set e.g. 6 seconds, then watch the NPC when an opponent approaches within 5 blocks.
9. Time Cell Moon Palace: check whether the original barrier and sure-hit persist. If it fails, capture `/jjknpc inspect <npc>`, the `latest.log` and a video.

**Status:** Build/packaging verified does not imply successful in-game testing; all new integrations are experimental, particularly custom NPC renderer paths and Time Cell Moon Palace.
