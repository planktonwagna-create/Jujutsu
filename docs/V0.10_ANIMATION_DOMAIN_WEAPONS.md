# JujutsuCraft NPC Compatibility v0.10 test

## Changes from v0.9
- **Animation playback:** The previous selection only covered a handful of
  moves. Selects bundled JujutsuCraft v51 `player_animation/*.json` poses for
  every move (specific move families where known; generic fallback otherwise).
  Charged moves play the original `charge1` animation, then play the attack
  pose on key release. No original animations are redistributed.
- **Humanoid rendering:** Adds a PlayerModel setupAnim TAIL hook for Easy NPC,
  keeps the original CustomNPCs ModelClassicPlayer TAIL hook and HumanoidModel
  fallback. After applying pose, synchronize the PlayerModel sleeve/pants/jacket
  geometry with the animated arms, legs and body.
- **Womb Profusion open/closed:** JJK v51's
  `DomainExpansionCreateBarrierProcedure` sets the open `cnt2` path for
  non-player entities when the original `SUKUNA_EFFECT` is present (or for
  Kenjaku entities). The addon uses its existing reversible Sukuna effect
  adapter for both Malevolent Shrine and Womb Profusion. Selecting open does
  not change Womb Profusion's model.
- **Domain HP threshold:** Per NPC 1–100% (default 100); gates ALL automatic
  domain casting, including enemy domain response. 100% = always eligible,
  restricted only by cooldown, combat AI/target/range and move mode;
  35% = requires NPC HP at or below 35% before beginning a domain. Manually
  triggered casts also respect the health gate and move cooldown.
  Settings are saved to NBT and shown with `/jjknpc inspect`.
- **Right-click special weapon abilities:** The Item Moves tab already
  recognized the original `supreme_martial_solution` (Kamutoke) procedure
  in v0.9; this build lets equipped supported cursed tools in EITHER hand
  appear in the tab. It calls the original item-right-click procedure only
  once per activation, with an independent editable cooldown, rather than
  looping and spawning duplicate effects. Native JJK right-click behavior
  may require additional per-item context; these cases need in-game testing.
- **Preserved:** v0.6 NPC melee damage/duel bridge; technique catalog,
  hold-to-charge, crouch variation and basic moves; RCT, anti-domain timing;
  Shrine normal/mutated appearance, open/closed selection.

## How to test
1. Back up the world; remove previous compatibility-addon JARs, install v0.10
   alone, and restart. Run `/jjknpc version` to confirm v0.10.
2. Enable an NPC move and observe whether the corresponding arm/pose animation
   appears on both CustomNPCs classic humanoids and Easy NPC player humanoids.
   Try Domain, Blue and a simple melee move separately.
3. Select cursed-spirit manipulation (`spirits`), enable Womb Profusion
   (`domain`) and use the Domain tab to switch its barrier Open/Closed.
4. Set the domain health threshold to 30%, save, and verify that automatic
   Domain Expansion starts only after dropping to 30% or lower.
   Use 100% to remove the HP restriction.
5. Give an NPC JujutsuCraft Supreme Martial Solution in its main or offhand.
   The Item Moves tab should appear; enable Kamutoke Discharge (Automatic/Both)
   and set a cooldown, e.g. 15 seconds. Verify a single special-use activation
   per cooldown in combat.
6. If animations do not display, compare `/jjknpc animate <npc> punch_right`
   with automatic casting and send `latest.log` plus a short video clip.
   The original JJK animation resources are categorized, not fully mapped
   one-to-one for every move: generic poses are an intended fallback.

## Limits
- Original NPC mods do not all use PlayerModel; only standard humanoids and
  CustomNPCs classic player models are targeted. Native JJK player animation
  playback is NOT guaranteed for custom skeletal NPC renderers.
- Animation assignment for ~400 new catalog entries is heuristic where
  the original mod doesn't expose an explicit player animation name.
- Forge build success tests compilation and packaging, not Minecraft rendering,
  real-time weapon effects or open domain world behavior.
