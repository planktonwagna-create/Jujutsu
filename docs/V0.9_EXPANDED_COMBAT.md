# JujutsuCraft NPC Compatibility v0.9 - Expanded input-driven skills

This is a test build for **JujutsuCraft ver51**, Forge 1.20.1, Easy NPC and
CustomNPCs GBPort. It preserves the confirmed v0.6 NPC-to-NPC damage/duel
compatibility, the v0.7 separate seconds-based cooldowns, and the v0.8
normal/mutated Shrine plus open/closed barrier selectors.

## Added / corrected

### Native charge input (not a pre-cast delay)
The compatibility bridge calls the original JJK ability every simulation tick.
It sets the original `PRESS_Z` input while a charge is being held, then
releases it. **Charge 0** is one activation tick/tap; **Charge 2** simulates
holding the key for **40 game ticks** (2 seconds) before releasing.
Charge inputs are exposed only for original ver51 procedures whose bytecode
contains a held-key (`PRESS_Z`) check. Native progression after release is
preserved; some native moves have prerequisites the addon cannot supply.

### Comprehensive character/technique catalog
Native dispatch tables were inspected from 47 v51 `CursedTechnique...`
procedure classes (including the misspelled MeiMei dispatch). The editor
now includes about 300 dispatch entries across 47+ selectable technique
families, rather than the previous 15 fixed groups. Previously configured
technique keys are preserved (e.g. `shrine`, `limitless`, `shadows`).
Additional discovered moves have default 5s cooldown, which is independently
editable; domains default 60s. Dispatch-specific skill numbers are assigned
to the caster for the original procedure invocation and immediately restored.

The table is **derived from v51 procedure call sites**; bytecode dispatch
heuristics can still misclassify nested/internal skills. Verify new moves
in-game individually; a procedure being present is NOT proof it works on NPCs.
Moves are labelled by their original procedure names when no stable English
translation was available.

### Crouch variants
For procedures whose original v51 implementation reads the sneak/Shift
state, the per-move timer screen also displays:
* **REGULAR** (no Shift input)
* **CROUCHING** (Shift input active during the original procedure)
* **ALTERNATE** (regular, crouch, regular, crouch, ... per successful start)

Alternation is stored independently for each NPC/move. The original crouch
state is restored after every procedure call. This is not an animation-only
variation, although only original JJK moves that actually inspect crouch
can produce a different ability.

### Native default melee skills
A **Melee** tab is always visible:
* Attack (original `AttackWeakProcedure`, JJK skill 0)
* Knockback Attack (original `AttackStrongProcedure`, JJK skill 1)
* Barrage (original `AttackContinueProcedure`, JJK skill 2)

Each has its own mode and editable cooldown. These skills are also available
when no cursed technique is selected.

### Conditional item skills
The **Item Moves** tab appears only if the NPC currently holds a JujutsuCraft
item with a recognized special-use procedure. It reads the NPC's main-hand
equipment on the client. It has an independent mode and cooldown for each
recognized item-specific skill. Inspected native ver51 item handlers:

* Nanami's weapon (Ratio Strike)
* Okkotsu's sword (Copy Technique)
* Supreme Martial Solution / Kamutoke
* Gavel, Big Gavel, Long Gavel, Executioner's Sword (Gavel Special)
* Broom (Broom Flight)
* Dragon Bone (Charge)
* Nyoi Staff (right-click skill)
* Harisen (swing skill)

Only those original procedures are directly invoked. Some might reject
NPC casters because of original Player-only checks; no replacement damage
mechanics are fabricated. Ordinary JJK clothing and material items do not
show the tab. The menu follows item swaps while open.

### Existing compatibility preserved
* NPC-to-NPC hit and duel bridge (v0.6)
* Seconds-based cooldowns and RCT/anti-domain timing
* Normal vs mutated Shrine appearance
* Open vs closed Shrine barrier
* Per-NPC data stored in its saved persistent NBT
* No addon cursed-energy consumption or prerequisite

## Testing instructions

1. Back up a disposable world. Remove older compat JARs; install v0.9 ONLY.
2. Confirm `/jjknpc version` reports **v0.9**. The editor says v0.9.
3. Use `/give @s jujutsunpccompat:editor_tool`, right-click an NPC.
4. Select a technique with the `< Technique` and `Technique >` buttons.
5. Enable a move in **Moves**, then choose it in **Timers**.
   For Blue, try 0-second charge and 2-second charge, and compare the effects.
6. For moves with a crouch check (e.g. Dismantle), cycle
   REGULAR -> CROUCHING -> ALTERNATE.
7. Open **Melee**, enable individual attack types and cooldowns.
8. Equip a supported native JJK weapon and reopen the editor. You should
   see an additional **Item Moves** tab.
9. Retest `/jjknpc duel <first> <second>` and basic attacks to verify the
   original damage fix remains active.
10. Send the relevant part of `latest.log` if one of the newly discovered
    original JJK procedures rejects an NPC.

**Build success only verifies Java integration, not v51's native gameplay
effects.** In-game testing is necessary before considering the expanded
move support complete.
