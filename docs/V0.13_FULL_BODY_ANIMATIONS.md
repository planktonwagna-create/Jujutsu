# v0.13 Full-Body NPC Animation Adapter (Forge 1.20.1 / JujutsuCraft v51)

**Purpose:** Fix rigid, incomplete-looking JujutsuCraft move animations on humanoid Easy NPC and CustomNPCs models. Tested for Java compilation and original JSON parsing; live animation rendering still needs confirmation.

## What changed
- **Preserves ORIGINAL JujutsuCraft animation files**; no lower-quality fabricated attack animations replace them.
- Reads both `rotation` and `position` keyframe tracks for all six humanoid bones.
- Combines the original `body` root rotation and `torso` rotation into Minecraft's one HumanoidModel torso instead of overwriting one with the other.
- Applies bone positions **relative to each bone's initial keyframe** to avoid moving the whole mesh by arbitrary original skeleton offsets. Translates Gecko Y-up to Minecraft ModelPart Y-down and clamps per-bone motion to 8 model pixels for safety.
- Stores last-frame position offsets per rendered ModelPart and restores them if the renderer hasn't reset them. This prevents accidental accumulation or permanent drift while preserving separate renderer customizations.
- Uses actual last keyframe timestamps rather than trusting misleading `animation_length` values (some originals say 180 seconds despite all action occurring by 0.125 seconds).
- Adds smoother motion progression, 100ms ease-in and 230ms ease-out back to the NPC's normal pose. Held charge maintains its pose until release.
- Keeps Easy NPC model-manager overlays and classic CustomNPCs/vanilla humanoid hooks.
- Preserves v0.12's improved UI, current-target Kashimo lightning, damage editing, melee fix, cooldowns, domains, grey hair item and other features.

## Install and test
1. Back up the world; remove ONLY the prior compatibility addon JAR. Install v0.13 by itself.
2. Run `/jjknpc version` and confirm **v0.13**.
3. With a compatible humanoid NPC, run `/jjknpc animate <npc-selector> punch_right`. Look for body twist, arm extension and leg balance.
4. Compare a quick punch, kick, a sword swing and a domain pose, using both Easy NPC and CustomNPCs if available.
5. If animation still does not display, provide a clip and `latest.log`. The model hooks only target humanoid/model-manager cases, not arbitrary GeckoLib/custom skeletal NPC models.

**Limitations:** The original files contain some animation bones absent in a vanilla six-part humanoid rig. They cannot be mapped perfectly without a custom skeleton. The new renderer may therefore be an approximation of the original, but should be more dynamic than v0.12. Success in GitHub Actions checks compilation, not live game rendering.
